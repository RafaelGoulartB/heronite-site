Appuyez sur <kbd>?</kbd> dans Heronite pour tous les raccourcis.

## Raccourcis disponibles partout

| Touches | Action |
|---|---|
| <kbd>Ctrl</kbd> <kbd>K</kbd> | Palette : pages, actions et jeux |
| <kbd>Ctrl</kbd> <kbd>,</kbd> | Réglages |
| <kbd>Ctrl</kbd> <kbd>N</kbd> | Ajouter un jeu |
| <kbd>Ctrl</kbd> <kbd>1</kbd> … <kbd>6</kbd> | Collection, Downloads, Wine Manager, Stores, Emulators, Statistics |
| <kbd>F5</kbd> | Actualiser les bibliothèques |
| <kbd>F11</kbd> | Plein écran |
| <kbd>?</kbd> | Cette liste |
| <kbd>Échap</kbd> | Fermer ou revenir |

## Raccourcis de la Collection

| Touches | Action |
|---|---|
| <kbd>/</kbd> ou <kbd>Ctrl</kbd> <kbd>F</kbd> | Rechercher |
| Toute lettre | Commencer une recherche |
| Flèches, <kbd>Début</kbd>, <kbd>Fin</kbd>, <kbd>Page préc.</kbd>, <kbd>Page suiv.</kbd> | Se déplacer |
| <kbd>Entrée</kbd> | Jouer ou installer |
| <kbd>Espace</kbd> | Sélectionner |
| <kbd>Maj</kbd> avec flèches | Sélectionner une plage |
| <kbd>Ctrl</kbd> <kbd>A</kbd> | Sélectionner tous les jeux affichés |
| <kbd>F3</kbd> | Modifier le jeu ou la sélection |
| <kbd>Ctrl</kbd> <kbd>Z</kbd> | Annuler la dernière modification des jeux sélectionnés |

## Raccourcis du champ de recherche

| Touches | Action |
|---|---|
| <kbd>↓</kbd> / <kbd>↑</kbd> | Aller aux résultats et revenir |
| <kbd>Entrée</kbd> | Jouer ou installer |
| <kbd>Échap</kbd> | Effacer puis quitter la recherche |

## Raccourcis de la palette de commandes

| Touches | Action |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>Page préc.</kbd> <kbd>Page suiv.</kbd> | Se déplacer |
| <kbd>Entrée</kbd> | Exécuter |
| <kbd>→</kbd> | Actions du jeu |
| <kbd>Tab</kbd> | Filtrer pages, actions ou jeux |

## Raccourcis des réglages

| Touches | Action |
|---|---|
| <kbd>Ctrl</kbd> <kbd>F</kbd> | Rechercher dans les réglages |
| <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>Début</kbd>, <kbd>Fin</kbd> | Se déplacer |
| <kbd>Entrée</kbd> ou <kbd>Espace</kbd> | Modifier |

## Raccourcis pendant le jeu

| Touches | Action |
|---|---|
| <kbd>F10</kbd> | Capture (modifiable dans **Settings → Screenshots**) |
| <kbd>Super</kbd> <kbd>G</kbd> | Interface en jeu (Linux, bêta) |
| <kbd>Maj</kbd> <kbd>F3</kbd> | Interface Epic dans les jeux compatibles |

Pour la manette et le mode console, voir [Mode console](/fr/docs/console-mode/).
