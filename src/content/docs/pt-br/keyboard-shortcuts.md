Aperte <kbd>?</kbd> no Heronite para ver todos os atalhos de teclado.

## Atalhos que funcionam em qualquer lugar

| Teclas | Ação |
|---|---|
| <kbd>Ctrl</kbd> <kbd>K</kbd> | Paleta de comandos: páginas, ações e jogos |
| <kbd>Ctrl</kbd> <kbd>,</kbd> | Configurações |
| <kbd>Ctrl</kbd> <kbd>N</kbd> | Adicionar um jogo |
| <kbd>Ctrl</kbd> <kbd>1</kbd> … <kbd>6</kbd> | Coleção, Downloads, Gerenciador do Wine, Lojas, Emuladores, Estatísticas |
| <kbd>F5</kbd> | Atualizar as bibliotecas |
| <kbd>F11</kbd> | Tela cheia |
| <kbd>?</kbd> | Esta lista |
| <kbd>Esc</kbd> | Fechar ou voltar |

## Atalhos da Coleção

| Teclas | Ação |
|---|---|
| <kbd>/</kbd> ou <kbd>Ctrl</kbd> <kbd>F</kbd> | Buscar |
| Qualquer letra | Começa uma busca com ela |
| Setas, <kbd>Home</kbd>, <kbd>End</kbd>, <kbd>PgUp</kbd>, <kbd>PgDn</kbd> | Mover |
| <kbd>Enter</kbd> | Jogar ou instalar |
| <kbd>Espaço</kbd> | Selecionar |
| <kbd>Shift</kbd> + setas | Selecionar um intervalo |
| <kbd>Ctrl</kbd> <kbd>A</kbd> | Selecionar todos os jogos visíveis |
| <kbd>F3</kbd> | Editar o jogo ou a seleção |
| <kbd>Ctrl</kbd> <kbd>Z</kbd> | Desfazer a última alteração nos jogos selecionados |

## Atalhos do campo de busca

| Teclas | Ação |
|---|---|
| <kbd>↓</kbd> / <kbd>↑</kbd> | Ir para os resultados e voltar |
| <kbd>Enter</kbd> | Jogar ou instalar o jogo |
| <kbd>Esc</kbd> | Limpar a busca e depois sair dela |

## Atalhos da paleta de comandos

| Teclas | Ação |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>PgUp</kbd> <kbd>PgDn</kbd> | Mover |
| <kbd>Enter</kbd> | Executar |
| <kbd>→</kbd> | As ações de um jogo |
| <kbd>Tab</kbd> | Só páginas, só ações ou só jogos |

## Atalhos das configurações

| Teclas | Ação |
|---|---|
| <kbd>Ctrl</kbd> <kbd>F</kbd> | Buscar nas configurações |
| <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>Home</kbd>, <kbd>End</kbd> | Mover |
| <kbd>Enter</kbd> ou <kbd>Espaço</kbd> | Alterar |

## Atalhos durante o jogo

| Teclas | Ação |
|---|---|
| <kbd>F10</kbd> | Captura de tela (mude em **Configurações → Capturas de tela**) |
| <kbd>Super</kbd> <kbd>G</kbd> | Overlay dentro do jogo (Linux, beta) |
| <kbd>Shift</kbd> <kbd>F3</kbd> | Overlay da Epic, nos jogos que usam |

Para o modo console e os botões do controle, veja [Modo console](/pt-br/docs/console-mode/).
