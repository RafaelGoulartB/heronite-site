Press <kbd>?</kbd> in Heronite to see this list.

## Anywhere

| Keys | Action |
|---|---|
| <kbd>Ctrl</kbd> <kbd>K</kbd> | Command palette: pages, actions, and games |
| <kbd>Ctrl</kbd> <kbd>,</kbd> | Settings |
| <kbd>Ctrl</kbd> <kbd>N</kbd> | Add a game |
| <kbd>Ctrl</kbd> <kbd>1</kbd> … <kbd>6</kbd> | Collection, Downloads, Wine Manager, Stores, Emulators, Statistics |
| <kbd>F5</kbd> | Refresh the libraries |
| <kbd>F11</kbd> | Fullscreen |
| <kbd>?</kbd> | This list |
| <kbd>Esc</kbd> | Close or go back |

## Collection

| Keys | Action |
|---|---|
| <kbd>/</kbd> or <kbd>Ctrl</kbd> <kbd>F</kbd> | Search |
| Any letter | Start a search with it |
| Arrows, <kbd>Home</kbd>, <kbd>End</kbd>, <kbd>PgUp</kbd>, <kbd>PgDn</kbd> | Move |
| <kbd>Enter</kbd> | Play or install |
| <kbd>Space</kbd> | Select |
| <kbd>Shift</kbd> + arrows | Select a range |
| <kbd>Ctrl</kbd> <kbd>A</kbd> | Select every game shown |
| <kbd>F3</kbd> | Edit the game or the selection |
| <kbd>Ctrl</kbd> <kbd>Z</kbd> | Undo the last change to selected games |

## Search field

| Keys | Action |
|---|---|
| <kbd>↓</kbd> / <kbd>↑</kbd> | To the results and back |
| <kbd>Enter</kbd> | Play or install the game |
| <kbd>Esc</kbd> | Clear the search, then leave it |

## Command palette

| Keys | Action |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>PgUp</kbd> <kbd>PgDn</kbd> | Move |
| <kbd>Enter</kbd> | Run |
| <kbd>→</kbd> | A game's actions |
| <kbd>Tab</kbd> | Only pages, only actions, or only games |

## Settings

| Keys | Action |
|---|---|
| <kbd>Ctrl</kbd> <kbd>F</kbd> | Search the settings |
| <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>Home</kbd>, <kbd>End</kbd> | Move |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Change |

## While playing

| Keys | Action |
|---|---|
| <kbd>F10</kbd> | Screenshot (can be changed in Settings → Screenshots) |
| <kbd>Super</kbd> <kbd>G</kbd> | In-game overlay (Linux, beta) |
| <kbd>Shift</kbd> <kbd>F3</kbd> | Epic's overlay, in games that use it |

For console mode and controller buttons, see [Console Mode](/docs/console-mode/).
